# Fonts

All three are under the SIL Open Font License 1.1 (the `*-OFL.txt` files beside them), which
lets them be bundled with the app as long as the licence goes with them, unchanged.

- `AntonSC-Regular.ttf`: Anton SC, by Vernon Adams, from
  [google/fonts](https://github.com/google/fonts/tree/main/ofl/antonsc). Words on buttons and
  dialog titles. Modified, as the licence allows (it reserves no font name): its lower-case
  letters are mapped straight to its small-capital glyphs, which the original shows only
  through the OpenType `smcp` feature, and iced applies no features.
- `Antonio-Regular.ttf`: Antonio, by Vernon Adams, from
  [googlefonts/antonioFont](https://github.com/googlefonts/antonioFont) (the static Regular;
  Google Fonts ships only the variable font). Small words.
- `Oswald-Regular.ttf`: Oswald, by Vernon Adams, from
  [googlefonts/OswaldFont](https://github.com/googlefonts/OswaldFont) (the static Regular).
  Everything else: names, values, timecodes, the timeline.
